# KJM-media-service

미디어 파일 업로드를 지원할 내부 파일 검사 및 S3 저장 요청 기능입니다. HTTP API와 DB 기록은 아직 제공하지 않습니다.

Java 17과 Gradle wrapper 9.9.2를 사용합니다. 최초 실행 시 Gradle 배포본과 테스트 의존성을 다운로드해야 할 수 있습니다.

Windows에서 테스트:

```powershell
.\gradlew.bat test
```

이 명령은 파일 검사·저장 서비스의 단위 테스트와 로컬 통신 장애 테스트, 테스트 전용 S3Mock을 사용한 AWS SDK 조건부 저장·키 충돌 테스트를 실행합니다. 테스트 결과는 `build/reports/tests/test/index.html`에서 확인할 수 있습니다. S3Mock은 테스트 의존성으로 실행되며 별도 S3 서버나 실제 AWS 자격 증명은 필요하지 않습니다.

JPEG, PNG, WebP 및 게시글용 MP4의 기본 식별 정보와 실제 읽은 크기를 확인합니다. 파일 전체의 안전성이나 재생 가능성은 보장하지 않습니다. 검사 도중 출력된 데이터는 임시 데이터이며 호출자가 실패 시 폐기해야 합니다.

저장 서비스는 검사한 임시 파일을 조건부 단일 PUT으로 전송하고 임시 파일을 정리합니다. 입력 스트림은 호출자가 닫습니다. S3 요청은 전용 클라이언트에서 한 번만 시도하며 결과가 불명확하면 키와 함께 오류를 반환합니다. 이를 복구할 영속 기록과 DB 연계가 없으므로 공개 업로드에는 연결하지 않습니다. 저장 성공 후 임시 파일 정리가 실패하면 저장 결과를 포함한 별도 오류를 반환합니다. 파일 읽기와 권한 검사는 후속 작업입니다.

S3Mock과 로컬 통신 검사는 실제 AWS의 동작을 보증하지 않습니다. 실제 AWS, HTTP 서버, DB 및 이들 사이의 복구는 아직 검증하지 않았습니다.
